# Northstar Tasks

A fictional sample project included with DevPilot AI so the hackathon demo can run without GitHub access or model credentials.

## Overview

Northstar Tasks is a tiny Python service that demonstrates account lookup and task listing. It is illustrative only; it is not a production application.

`backend/demo_smells.py` contains clearly labeled, static-only examples for the
scanner walkthrough. It is never imported by the sample application.

## Run tests

```bash
python -m pytest
```
